# ✳ EleForSs SpotiLyrics `v1.0 (beta)`

Эстетичный генератор карточек с текстом треков в стиле **Spotify / Opium** с умным AI-поиском, автоматической адаптацией цвета под обложку альбома и экспортом в PNG / анимацию.

## Возможности v1.0 (beta)
- **AI-поиск треков и ссылок Spotify:** ввод названия, строчки из песни или прямой ссылки `://spotify.com...`.
- **Интерактивный конструктор куплета:** выбор от **1 до 4 строчек** с выделением главной акцентной строки.
- **Адаптивная цветовая система:** автоматический подбор оттенка карточки под загруженную обложку альбома + встроенная палитра.
- **3 фактуры карточки:** `Градиент`, `Матовый`, `Глянцевый`.
- **3 темы интерфейса:** `Dark`, `White`, `Chrome`.
- **Экспорт:** сохранение в высоком разрешении `PNG` или зацикленной анимации с эквалайзером.

## Быстрый деплой на Vercel
1. Импортируй этот репозиторий в **Vercel**.
2. В настройках проекта (`Settings -> Environment Variables`) добавь бесплатный API-ключ из Google AI Studio:
   - `GEMINI_API_KEY` = `твой_ключ`
3. Нажми **Deploy**.
